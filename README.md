# Cap EPP

Outil pédagogique responsive pour animer des mises en situation autour de l'entretien de parcours professionnel.

## Mise en ligne sur GitHub Pages
1. Créez un dépôt public.
2. Ajoutez `index.html`, `styles.css` et `app.js` à la racine.
3. Dans **Settings > Pages**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/root`.

## Fonctionnalités
- 8 situations réalistes
- 3 rôles : conduite, salarié, observation
- niveaux guidé, standard et challenge
- minuteur
- grille d'observation et score
- quiz de repérage
- sauvegarde locale du dernier bilan

## Données
Aucune donnée n'est envoyée. La sauvegarde utilise uniquement le stockage local du navigateur.
